# Data terms

The Complete Pokémon TCG Dataset (`data/`) is published under custom terms. On Kaggle this is the license
option "Other (specified in description)". No standard license fits, because most of the content is not the
author's to license:
- **Card content:** card names, card text, set names and the linked card images are © The Pokémon Company,
  Nintendo, Creatures Inc. and GAME FREAK inc.
- **Upstream compilation:** the card data was compiled by the
  [PokemonTCG/pokemon-tcg-data](https://github.com/PokemonTCG/pokemon-tcg-data) project, which publishes no
  license. That project is now kept for historical use, and this dataset is a snapshot from November 2026.

## You may
- Use the dataset for **non-commercial research, education, analysis and personal projects**, including
  Kaggle notebooks and derived analyses.

## You must
- **Credit both sources:** *"The Complete Pokémon TCG Dataset by Cristobal Mitchell"* (with a link to
  https://www.kaggle.com/datasets/cristobalmitchell/pokemon-tcg or https://github.com/cristobalmitchell/pokemon-tcg)
  and *"card data compiled by PokemonTCG/pokemon-tcg-data"*.
- **Keep it non-commercial:** do not sell the data or use it in a commercial product.
